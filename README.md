## English

**Projects, time and budgets — in one place.**

ProjectCheck keeps customers, projects, people, time entries and optional budgets on the Nextcloud you already host. Book time against projects. Resolve rates on the server from dated history. See remaining budget before the month runs away.

**Free web app** (AGPL-3.0-or-later). Companion apps: https://nextcloud.software-by-design.de/

### Why teams install it

- Customers and projects with status, dates, search and sort
- Invite Nextcloud users with roles and permissions
- Book, filter and export time on projects
- Optional budgets; server-side cost pricing with append-only rate history
- Dashboard; files on projects; admin and personal settings

### Clear limits

- Mobile may preview rates; the server stays authoritative.
- Prefer `ProjectCheck*` in new integrations — `ProjectControl*` names are deprecated aliases.

### Requirements

- Nextcloud 32–34 · PHP 8.2–8.5 · MySQL/MariaDB or PostgreSQL

### Install

**App Store (recommended):** [apps.nextcloud.com/apps/projectcheck](https://apps.nextcloud.com/apps/projectcheck)

**From Git:** clone into `apps/projectcheck`, then `composer install --no-dev`, `npm ci`, `npm run build`, `php occ app:enable projectcheck`.

## Deutsch

**Projekte, Zeit und Budgets — an einem Ort.**

ProjectCheck führt Kunden, Projekte, Personen, Zeiteinträge und optionale Budgets in der Nextcloud, die Sie schon betreiben. Zeit auf Projekte buchen. Tarife serverseitig aus Historie auflösen. Restbudget sehen, bevor der Monat davonläuft.

**Kostenlose Web-App** (AGPL-3.0-or-later). Companion-Apps: https://nextcloud.software-by-design.de/

### Warum Teams es einsetzen

- Kunden und Projekte mit Status, Terminen, Suche und Sortierung
- Nextcloud-Benutzer mit Rollen und Rechten
- Zeit am Projekt buchen, filtern und exportieren
- Optionale Budgets; serverseitige Kostentarifierung
- Dashboard; Dateien am Projekt; Einstellungen

### Klare Grenzen

- Mobile kann Tarife nur voranzeigen; maßgeblich ist der Server.
- Für neue Anbindungen `ProjectCheck*` — `ProjectControl*` sind veraltete Aliase.

### Voraussetzungen

- Nextcloud 32–34 · PHP 8.2–8.5 · MySQL/MariaDB oder PostgreSQL

### Installation

**App Store (empfohlen):** [apps.nextcloud.com/apps/projectcheck](https://apps.nextcloud.com/apps/projectcheck)

**Aus Git:** nach `apps/projectcheck` klonen, `composer install --no-dev`, `npm ci`, `npm run build`, `php occ app:enable projectcheck`.
